
# Password Analyzer — Kali Edition 🛡️

A lightweight CLI tool to analyze password strength and check against the `rockyou.txt` leak database.

---

## ⚙️ Features

- 💪 Password strength analysis using entropy
- 🔎 Checks password complexity
- 📛 Optional leak check with `rockyou.txt`
- 🏃 Runs from terminal on **Kali Linux**
- 📁 Portable & simple

---

## 🚀 Installation

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/password-analyzer.git
cd password-analyzer
chmod +x password_analyzer.py
sudo ln -s $PWD/password_analyzer.py /usr/local/bin/pw-analyze
